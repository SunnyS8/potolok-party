Приоритетный роадмап
1. Срочные исправления и выравнивание
Убрать раздельную логику drawing / calculator и оставить одну рабочую версию калькулятора.
Привести UI в единое состояние: потолки / стены / комплекс на всех страницах и в результатах.
Исправить пути для развёртывания (GitHub Pages / Vercel) и проверить, что calculator.html загружается стабильно.
Убрать устаревшие упоминания СИС в интерфейсе, если продукт продаётся как единый сервис.
2. Быстрые улучшения UX
Сделать понятный итог расчёта:
цена потолка
цена стен
цена комплекса
скидка
состав сметы (рулоны, профиль, монтаж)
Добавить сохранение/поделиться расчётом (ссылка или PDF) для клиента.
Упростить лид‑форму: захват контакта не только после расчёта, но и прямо из калькулятора/чата.
Улучшить чат-виджет:
явное предложение «заказать замер»
«Мне нужен расчёт»
«Скажите цену» / «Позвоните мне»
3. Менеджерский поток и CRM
Сделать менеджерскую панель удобнее:
фильтры по статусам лидов и сделок
поиск по телефону/имени
быстрый переход от лида к сделке
экспорт CSV/XLSX
Добавить историю и комментарии по лидy/сделке, чтобы менеджер видел контекст.
Разграничить права доступа: вход менеджера, демо‑режим, гостевой просмотр.
4. Надежность и данные
Перенести хранение с JSON → более стабильно:
SQLite / Postgres / другой файл-база
Централизовать прайс: один источник цен для калькулятора, API и менеджера.
Добавить метрики:
количество лидов
конверсия в сделки
средняя сумма
источники заявок
5. Автоматизация и рост
Интеграции CRM:
Bitrix24/MegaCRM сделать рабочими и надежными
добавить уведомления в Telegram/Email
Сделать AI-ассистента менеджера более полезным:
шаблоны КП
ответы на FAQ
контекст по текущим лидам
Внедрить режим «комплексного предложения»:
предложение потолка + стен с фиксированной скидкой
готовый вариант «комплекс»
Рекомендованная последовательность
Фаза 1: пункты 1–4
Фаза 2: пункты 5–8
Фаза 3: пункты 9–12
Фаза 4: пункты 13–17
Если нужно, могу сразу прописать roadmap с задачами по спринтам и оценками времени.
