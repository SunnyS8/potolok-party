
## 1. Цветовые токены

### Базовые токены

- **BG/Base** — фон приложения  
  - `BG/Base = #F5F5F7` (светлый нейтральный фон для всех экранов). [kokoc](https://kokoc.com/blog/prodayushchie-cveta-dlya-sajta/)
- **Text/Primary** — основной текст  
  - `Text/Primary = #1F2933` (темно-серый, комфортнее, чем чистый черный). [habr](https://habr.com/ru/articles/785272/)
- **Text/Secondary** — вторичный текст, подписи  
  - `Text/Secondary = #6B7280` (серый для менее важной информации). [creamcrm](https://creamcrm.ru/blog/kak-v-crm-nastroit-cveta-i-dizajn-interfejsa-dlya-sotrudnikov)

### Поверхности и границы

- **Surface/Card** — фон карточек, панелей  
  - `Surface/Card = #FFFFFF` (чистый белый для блоков на светлом фоне). [creamcrm](https://creamcrm.ru/blog/kak-v-crm-nastroit-cveta-i-dizajn-interfejsa-dlya-sotrudnikov)
- **Border/Light** — легкие рамки и разделители  
  - `Border/Light = #E5E7EB` (тонкий серый для линий и контуров). [adminlte](https://adminlte.io/blog/best-admin-dashboard-color-schemes/)
- **Border/Medium** — более заметные границы (полей ввода, карточек)  
  - `Border/Medium = #CBD2D9`. [creamcrm](https://creamcrm.ru/blog/kak-v-crm-nastroit-cveta-i-dizajn-interfejsa-dlya-sotrudnikov)

### Акцентные цвета

- **Accent/Primary** — главный акцент (кнопки действий)  
  - `Accent/Primary = #2563EB` (синий для CTA-кнопок и ключевых элементов). [adminlte](https://adminlte.io/blog/best-admin-dashboard-color-schemes/)
- **Accent/Success** — успех, положительные статусы  
  - `Accent/Success = #16A34A` (зелёный для “Замер назначен”, “Успешно”). [kokoc](https://kokoc.com/blog/prodayushchie-cveta-dlya-sajta/)
- **Accent/Error** — ошибки, критические статусы  
  - `Accent/Error = #DC2626` (красный для валидации и важных предупреждений). [habr](https://habr.com/ru/articles/785272/)
- **Accent/Warning** — мягкие предупреждения  
  - `Accent/Warning = #F59E0B` (желтоватый для “Требует внимания, но не критично”). [kokoc](https://kokoc.com/blog/prodayushchie-cveta-dlya-sajta/)

### Состояния элементов

- **State/HoverPrimary** — наведение на главную кнопку  
  - `State/HoverPrimary = #1D4ED8` (чуть более тёмный синий). [adminlte](https://adminlte.io/blog/best-admin-dashboard-color-schemes/)
- **State/Disabled** — выключенные кнопки, поля  
  - `State/DisabledBG = #E5E7EB`, `State/DisabledText = #9CA3AF`. [creamcrm](https://creamcrm.ru/blog/kak-v-crm-nastroit-cveta-i-dizajn-interfejsa-dlya-sotrudnikov)

## 2. Типографика (Text Styles)

Базовый шрифт: **Inter** (или Roboto / Manrope) с кириллицей, единое семейство для всего интерфейса. [tilda](https://tilda.education/articles-fonts)

### Заголовки

- **Text/H1** — главный заголовок экрана  
  - Font: Inter, 28 px, SemiBold (600)  
  - Line-height: 130%  
  - Color: `Text/Primary`  
  - Применение: названия разделов (“Заявки”, “Калькулятор сметы”, “Визуализация”). [habr](https://habr.com/ru/articles/675658/)

- **Text/H2** — заголовки блоков  
  - Font: Inter, 20 px, Medium (500)  
  - Line-height: 130%  
  - Color: `Text/Primary`  
  - Применение: “Данные клиента”, “Параметры потолка”, “Итоговая стоимость”. [habr](https://habr.com/ru/articles/675658/)

### Основной текст

- **Text/Body** — основной текст и поля  
  - Font: Inter, 16 px, Regular (400)  
  - Line-height: 145–150%  
  - Color: `Text/Primary`  
  - Применение: описания, значения полей, текст внутри карточек. [tilda](https://tilda.education/articles-fonts)

- **Text/BodySecondary** — пояснения, вторичный текст  
  - Font: Inter, 14 px, Regular (400)  
  - Line-height: 145%  
  - Color: `Text/Secondary`  
  - Применение: подсказки рядом с полями, вспомогательные описания. [habr](https://habr.com/ru/articles/675658/)

### Мелкий текст

- **Text/Caption** — подписи, label над полем  
  - Font: Inter, 13 px, Regular (400)  
  - Line-height: 140%  
  - Color: `Text/Secondary`  
  - Применение: метки полей формы, мини-пояснения. [habr](https://habr.com/ru/articles/675658/)

- **Text/Status** — бейджи статусов (“Новый”, “Замер назначен”)  
  - Font: Inter, 12–13 px, Medium (500)  
  - Line-height: 130–140%  
  - Color: зависит от статуса (например, зелёный текст или белый на цветном бейдже). [altcraft](https://altcraft.com/ru/blog/kak-sozdat-dizajn-crm-kommunikacii)

### Кнопки

- **Text/Button** — текст в кнопках  
  - Font: Inter, 14–16 px, Medium (500)  
  - Line-height: 120–130%  
  - Color: обычно `#FFFFFF` на `Accent/Primary`  
  - Применение: “Рассчитать”, “Записать на замер”, “Сохранить”. [altcraft](https://altcraft.com/ru/blog/kak-sozdat-dizajn-crm-kommunikacii)

- Фон: `Surface/Card`  
- Бордер: `Border/Light`  
- Border-radius: 8–10 px  
- Заголовок (имя, тип запроса): `Text/Body` / `Text/H2`  
- Статус: `Text/Status` + цветной бейдж (фон — `Accent/Success` / `Accent/Warning`)  
- Доп. текст: `Text/BodySecondary`. [creamcrm](https://creamcrm.ru/blog/kak-v-crm-nastroit-cveta-i-dizajn-interfejsa-dlya-sotrudnikov)
Такой тип карточек и блоков хорошо работает в CRM-интерфейсах: видно главное, остальные детали строго структурированы. [creamcrm](https://creamcrm.ru/blog/kak-v-crm-nastroit-cveta-i-dizajn-interfejsa-dlya-sotrudnikov)
### Блок “Итоговая стоимость”
- Заголовок: `Text/H2` (“Итоговая стоимость”)  
- Основная цифра цены: Inter, 20–24 px, SemiBold, цвет `Text/Primary`  
- Доп. пояснение: `Text/BodySecondary`, описывает, что входит в цену. [apsolyamov](https://apsolyamov.ru/blog/onlajn_kalkuljator_stoimosti_kak_prevratit_posetitelej_sajta_v_pokupatelej/2025-10-01-618)
- Фон блока может быть чуть отличаться (например, `#F9FAFB`) для акцентирования. [creamcrm](https://creamcrm.ru/blog/kak-v-crm-nastroit-cveta-i-dizajn-interfejsa-dlya-sotrudnikov)

## 4. Layout и отступы (минимум)
- Базовая сетка: 8 px (все отступы кратны 8: 8, 16, 24, 32 px). [adminlte](https://adminlte.io/blog/best-admin-dashboard-color-schemes/)
- Отступ между полями в форме: 16–20 px.  
- Отступ между блоками (панелями): 24–32 px.  

Это даёт ровный ритм интерфейса и уменьшает визуальный хаос. [artean](https://artean.ru/blog/web-development/effektivnyj-dizajn-crm-uluchshenie-interfejsa-dlja-rosta-biznesa/)

***
## 5. Как этим пользоваться
- В Figma завести страницу `Design System` с разделами: Colors, Typography, Components.  
- Цветовые токены использовать как переменные (BG/Base, Text/Primary и т.д.), а не как “просто hex”.  
- Каждый экран (бот, калькулятор, CRM-список, карточка клиента) собирать только из этих стилей и компонентов — без “самодеятельности”.
